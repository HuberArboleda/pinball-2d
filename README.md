# NEON PINBALL

Juego de Pinball 2D estilo arcade neón hecho con HTML5 `<canvas>`, CSS, JavaScript, Matter.js y audio sintetizado con Web Audio API.

## Controles

| Acción | Teclas |
| --- | --- |
| Flipper izquierdo | `A` o `←` |
| Flipper derecho | `D` o `→` |
| Cargar y lanzar bola | Mantener y soltar `Espacio` |
| Iniciar / Reiniciar partida | `Espacio` o `Enter` |
| Silenciar / Activar sonido | `M` |

## Cómo abrirlo

Desde la carpeta del proyecto, ejecuta:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000` en tu navegador
